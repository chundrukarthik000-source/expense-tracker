# Expense Tracker

A modern web-based Expense Tracker application built with HTML, CSS, JavaScript, and Firebase. This application helps users keep track of their income and expenses securely.

## Features
- **User Authentication:** Secure sign up and login using Firebase Authentication.
- **Expense Tracking:** Add, view, and manage daily expenses and income.
- **Real-time Database:** Data is stored and synced in real-time using Firebase Firestore.
- **Responsive Design:** A beautiful and modern user interface that works on all devices.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Firebase (Authentication & Firestore)

## Getting Started

1. Clone the repository.
2. Configure Firebase in `firebase-config.js` with your own Firebase project credentials.
3. Open `index.html` in your browser or serve using a local development server (or use Firebase Hosting).
