# 💰 Expense Tracker

![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)
**[View Live Application](https://expenses-tracker-c4f43.web.app/login.html)**

A modern, web-based **Expense Tracker** application built with HTML, CSS, JavaScript, and Firebase. This application empowers users to seamlessly track their daily income and expenses securely, providing a clear overview of their financial health.

## 🚀 Live Deployment
Check out the live deployment of the app here: **[Expense Tracker Live Demo](https://expenses-tracker-c4f43.web.app/login.html)**

## ✨ Key Features
- **User Authentication:** Secure sign-up and login functionality powered by Firebase Authentication. Users have their own private dashboard.
- **Comprehensive Expense Tracking:** Easily add, view, manage, and categorize daily expenses and income.
- **Real-time Database:** All financial data is securely stored and synced in real-time using Firebase Firestore, ensuring data is never lost.
- **Dynamic UI:** A beautiful, intuitive, and modern user interface that is fully responsive and works perfectly across all devices (mobile, tablet, desktop).
- **Instant Calculations:** Automatically calculates and updates your total balance, income, and expenses as soon as you add new records.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend/Database:** Firebase (Authentication, Cloud Firestore)
- **Hosting:** Firebase Hosting

## 📂 Project Structure
- `index.html` - The main dashboard where users manage their expenses.
- `login.html` & `signup.html` - Authentication pages.
- `style.css` - Custom styling and responsive design.
- `app.js` & `auth.js` - Core logic for authentication and data management.
- `firebase-config.js` - Firebase initialization and configuration.

## ⚙️ Getting Started (Local Development)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/chundrukarthik000-source/expense-tracker.git
   ```
2. **Configure Firebase:** 
   Update `firebase-config.js` with your own Firebase project credentials if you wish to run it against your own database.
3. **Run the App:**
   Open `index.html` in your browser or serve using a local development server (like VS Code Live Server).
